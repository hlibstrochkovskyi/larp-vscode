# Changelog

## 0.1.0 — 2026-10-19

- Initial language support for LARP compiler v0.1.0-preview.1.
- Recognize `.larp` source files with TextMate syntax highlighting.
- Add bracket matching/closing, comments, indentation, and 18 snippets.
- Add scope tests against 102 upstream programs and the compiler's lexer spans.
- Add editor integration tests, compiler snippet checks, and local VSIX packaging.
